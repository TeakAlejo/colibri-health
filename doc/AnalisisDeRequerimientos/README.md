# Análisis de Requerimientos

## Objetivo

Este documento tiene como propósito identificar, analizar y documentar los requerimientos funcionales y no funcionales del sistema **Hummi**. La información aquí presentada servirá como base para las etapas de diseño, arquitectura, implementación y pruebas del proyecto.

## Alcance

Hummi es una aplicación móvil orientada al seguimiento nutricional y al control de hábitos saludables. Permitirá a los usuarios calcular sus necesidades energéticas, registrar su alimentación diaria, monitorear su progreso corporal y visualizar estadísticas relacionadas con su nutrición.

El proyecto está inspirado en las necesidades del **Proyecto Colibrí** de la Universidad Icesi, con el objetivo de facilitar el seguimiento de planes nutricionales para personas que desean perder grasa, mantener su peso o aumentar masa muscular.

La primera versión (MVP) incluirá únicamente las funcionalidades esenciales para ofrecer una experiencia completa de seguimiento nutricional. Funcionalidades avanzadas, como inteligencia artificial, panel administrativo y análisis avanzados, serán incorporadas en versiones posteriores.

## Convenciones

Durante el desarrollo del proyecto, los requerimientos estarán clasificados según su prioridad y versión de implementación.

| Prioridad | Descripción |
|-----------|-------------|
| **Alta** | Funcionalidad indispensable para la primera versión (MVP). |
| **Media** | Funcionalidad planificada para la versión 2. |
| **Baja** | Funcionalidad de innovación o prevista para versiones futuras. |

## Contenido

Este análisis de requerimientos está dividido en los siguientes documentos:

- Requerimientos Funcionales
- Requerimientos No Funcionales
- Historias de Usuario
- Casos de Uso

Cada uno de estos documentos describe una parte específica del comportamiento esperado del sistema y servirá como guía durante el desarrollo del proyecto.
