# Requerimientos Funcionales

## Objetivo

Definir las funcionalidades que el sistema Hummi deberá ofrecer a los usuarios durante las diferentes etapas del proyecto.

## Requerimientos

| ID | Requerimiento | Descripción | Prioridad / Versión |
|----|---------------|-------------|---------------------|
| RF-01 | Registro e Inicio de Sesión | El sistema debe permitir el registro, inicio y cierre de sesión de usuarios de forma segura. | Alta (MVP V1) |
| RF-02 | Perfil Antropométrico | El usuario podrá ingresar y actualizar edad, sexo, peso, estatura y nivel de actividad física. | Alta (MVP V1) |
| RF-03 | Cálculo de TMB y TDEE | El sistema calculará automáticamente la Tasa Metabólica Basal (TMB) y el Gasto Energético Total Diario (TDEE) utilizando la fórmula de Mifflin-St. Jeor. | Alta (MVP V1) |
| RF-04 | Definición del Objetivo | El usuario podrá seleccionar un objetivo nutricional: Déficit, Mantenimiento o Superávit. | Alta (MVP V1) |
| RF-05 | Distribución de Macronutrientes | El sistema calculará automáticamente la meta diaria de proteínas, carbohidratos y grasas según el objetivo calórico. | Alta (MVP V1) |
| RF-06 | Dashboard Diario | El sistema mostrará el resumen diario de calorías consumidas, calorías restantes y el progreso de macronutrientes. | Alta (MVP V1) |
| RF-07 | Búsqueda de Alimentos | El usuario podrá buscar alimentos dentro de una base de datos nutricional y consultar su información. | Alta (MVP V1) |
| RF-08 | Registro de Comidas | El usuario podrá registrar alimentos en desayuno, almuerzo, cena o snacks indicando la cantidad consumida. | Alta (MVP V1) |
| RF-09 | Historial Diario | El usuario podrá consultar el historial de comidas y consumo nutricional de días anteriores. | Alta (MVP V1) |
| RF-10 | Edición de Registros | El usuario podrá modificar o eliminar alimentos previamente registrados. | Alta (MVP V1) |
| RF-11 | Registro de Agua | El sistema permitirá registrar el consumo diario de agua y mostrar el progreso frente a una meta. | Media (V2) |
| RF-12 | Seguimiento Corporal | El usuario podrá registrar peso, medidas corporales y fotografías para visualizar su progreso físico. | Media (V2) |
| RF-13 | Alimentos Personalizados | El usuario podrá crear alimentos personalizados cuando estos no existan en la base de datos. | Media (V2) |
| RF-14 | Favoritos | El usuario podrá marcar alimentos como favoritos para acceder rápidamente a ellos. | Media (V2) |
| RF-15 | Recetas Personalizadas | El usuario podrá guardar combinaciones de alimentos como recetas para registrarlas rápidamente. | Media (V2) |
| RF-16 | Estadísticas | El sistema mostrará estadísticas del progreso nutricional y corporal mediante gráficas y resúmenes. | Media (V2) |
| RF-17 | Identificación de Platos mediante IA | El sistema permitirá identificar alimentos a partir de una fotografía utilizando modelos de inteligencia artificial para estimar calorías y porciones. | Baja (V3) |
| RF-18 | Panel Administrativo Colibrí | Entrenadores o nutricionistas podrán consultar el progreso y evolución de los participantes del Proyecto Colibrí. | Baja (V3) |
