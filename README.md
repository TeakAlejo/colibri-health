# Colibrí Health

Colibrí Health es una plataforma de seguimiento nutricional desarrollada como un proyecto personal con el objetivo de apoyar el Proyecto Colibrí de la Universidad Icesi.

El proyecto nace a partir de mi experiencia personal aprendiendo a mejorar mis hábitos alimenticios y llevar un control de mi nutrición durante un proceso de déficit calórico. Durante este proceso identifiqué la necesidad de una herramienta que facilitara el cálculo de calorías y macronutrientes, así como el seguimiento del progreso físico de una manera sencilla e intuitiva.

Mi objetivo es desarrollar una aplicación que pueda convertirse en una herramienta de apoyo para estudiantes universitarios y, en el futuro, aportar valor al Proyecto Colibrí.

## Objetivos

La plataforma busca permitir a los usuarios:

- Calcular sus requerimientos calóricos diarios.
- Calcular la distribución de proteínas, grasas y carbohidratos.
- Registrar alimentos y comidas.
- Llevar seguimiento del peso y otras medidas corporales.
- Visualizar estadísticas e historial de progreso.
- Facilitar el acompañamiento nutricional dentro del Proyecto Colibrí.

## Funcionalidades planeadas

### Primera versión

- Registro e inicio de sesión.
- Cálculo de TMB (Tasa Metabólica Basal).
- Cálculo de TDEE (Gasto Energético Diario).
- Cálculo de calorías para déficit, mantenimiento y superávit.
- Cálculo automático de macronutrientes.

### Futuras versiones

- Registro diario de comidas.
- Base de datos de alimentos.
- Estadísticas y gráficos.
- Seguimiento del progreso físico.
- Panel para administradores del Proyecto Colibrí.
- Recomendaciones nutricionales.
